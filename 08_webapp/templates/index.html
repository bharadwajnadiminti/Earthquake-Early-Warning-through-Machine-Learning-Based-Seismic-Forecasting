About this forecast

Each cell shows the probability that a magnitude ≥4.5 earthquake occurs inside it within the next 7 days, estimated from rolling seismicity rate, magnitude statistics, Gutenberg-Richter b-value, and radiated energy computed as of the forecast date. Only "active" grid cells (≥50 historical events) are modeled — see the project README for the full target definition and known limitations (short ~20-month catalog, coarse global grid).
